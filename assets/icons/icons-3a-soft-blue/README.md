# Iconos "Soft Blue Glow" (opción 3a)

6 iconos SVG animados para las tarjetas de servicios. Cada archivo es un badge de 52x52 (viewBox) con:
- Fondo degradado azul cielo (#38bdf8) con halo respirando (glow pulse continuo).
- Glifo en blanco azulado (#eaf6ff) sobre el badge.
- Acento / punto animado en azul cielo (#38bdf8) — parpadeo, giro o barrido según el ícono.

Archivos:
1. 01-ai-training-for-your-team.svg
2. 02-custom-ai-agents.svg
3. 03-strategic-ai-consulting.svg
4. 04-back-office-ai-sprint.svg
5. 05-documents-and-invoices-ai.svg
6. 06-financial-copilot.svg

Uso: cada SVG es standalone (incluye sus propios <defs>/@keyframes), se puede insertar directo como <img src="..."> (las animaciones seguirán funcionando) o inline como <svg> en el HTML/JSX.
Tamaño recomendado: 52-64px. Colores clave: acento #38bdf8, glifo #eaf6ff, glow rgba(56,189,248,.4).
